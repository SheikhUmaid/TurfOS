Questions?

Good ones

How much does TurfOS cost?

The first month is ₹4,000, which covers activation, setup and onboarding. From the second month on, the subscription is ₹1,299 per month. There are no feature tiers, and every feature is included.

What does the activation include?

We set up your TurfOS account, add your pitches, sessions and slot pricing, and walk you through the admin panel so you can start taking bookings right away.

Can I manage more than one pitch or sport?

Yes. Services & Pitches lets you add multiple pitches (for example football and cricket), each with its own slots, pricing and calendar.

Can I charge more for peak hours?

Yes. Time Slots & Pricing lets you set a different price for each session (Morning, Afternoon, Floodlit Evening, Late Night), so prime-time slots can cost more.

How do coupons work?

Create a code with a percentage discount, a start date, an end date and an optional usage limit. Players apply it at checkout, and you can track usage for each coupon in the admin panel.

Can I still take walk-in or phone bookings?

Yes. Use Quick Booking in the admin panel to add a booking in seconds. It goes into the same calendar as online bookings, so a slot can never be booked twice.
